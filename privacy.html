어떤 정보를 사용하나요?

  • Google 이메일·계정 식별자: 사용자가 지정한 계정으로 연결했는지 확인해요.
  • Google 연결 토큰: 사용자가 동의한 범위에서 구글시트를 읽고 갱신해요. 비밀번호는 Google 로그인 화면에 직접 입력해요.
  • 도서 목록·동기화 정보: 추천도서와 게시글 출처, 마지막 자동 입력값, 도서 식별자를 보관하여 중복과 덮어쓰기를 줄여요.
  • 공지 캐시·실행 및 오류 기록: 공개 공지를 효율적으로 다시 확인하고 실패한 작업을 복구해요.

어디에 보관하나요?

도서 목록과 숨김 동기화 정보는 사용자가 지정한 Google Drive의 구글시트에 보관해요. 연결 토큰은 현재 Windows 사용자에게 묶인 암호화 기능으로 보호하여 프로젝트 폴더에 보관해요. 캐시·실행 이력·대기 목록도 프로젝트 폴더에 보관해요.

배포 ZIP에는 개인 로그인 토큰·개인 설정·도서 데이터베이스·캐시를 포함하지 않아요. 앱을 식별하는 전용 인증 설정은 사용자의 선택에 따라 포함할 수 있어요.

어디로 전달하나요?

프로그램은 Google 인증 및 Drive·Sheets 서비스와 공개 공지 사이트에 연결해요. Google 사용자 데이터는 사용자가 요청한 도서 목록 관리와 계정 확인에만 이용해요. 광고 제공, 판매, 범용 AI 모델 학습을 위해 Google 사용자 데이터를 이용하지 않아요. 프로그램의 평소 갱신 과정은 AI API를 호출하지 않아요.

사용자가 별도로 AI 에이전트에 프로젝트 폴더를 제공하면, 제공한 자료에는 해당 AI 서비스의 정책이 적용될 수 있어요. 이 안내 웹사이트는 방문자용 로그인·분석 스크립트·광고를 사용하지 않아요. GitHub Pages에 공개하는 경우 호스팅 사업자는 보안 목적의 접속 정보를 처리할 수 있어요. GitHub 개인정보처리방침을 확인해 주세요.

이 앱의 Google API에서 받은 정보 사용·전달은 Google API 서비스 사용자 데이터 정책의 제한된 사용 요구사항을 준수하는 범위로 한정해요.

연결 해제와 삭제는 어떻게 하나요?

Google 계정의 연결 관리에서 이 앱의 권한을 해제할 수 있어요. 프로그램을 종료하고 프로젝트의 개인 토큰·로컬 데이터 파일을 삭제하면 컴퓨터에 보관된 기록을 지울 수 있어요. 구글시트는 Google Drive에서 직접 관리하거나 삭제해요. 로컬 프로그램을 지워도 구글시트를 자동 삭제하지 않아요.

문의는 Google 연결 화면에 표시되는 사용자 지원 이메일로 보내 주세요. 데이터 처리 방식이 바뀌면 이 문서의 날짜와 내용을 갱신해요.
