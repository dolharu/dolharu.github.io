박자세 공지에 올라온 목요특강 추천도서를 모아, 사용자가 지정한 Google 계정의 구글시트에 기록하는 포터블 프로그램이에요.

버튼을 누를 때만 갱신해요

  1. 프로젝트 폴더에서 프로그램을 실행해요.
  2. 사용할 Google 계정을 설정하고 직접 로그인·연결 동의를 해요.
  3. 갱신하기를 누르면 새 공지를 확인하고 내 구글시트에 반영해요.

첫 엑셀 이전을 검증한 뒤에는 구글시트를 기준으로 이어가요. 직접 수정한 값은 마지막 자동 입력값과 대조하여 보존해요. 불확실한 정보는 확인 대기로 남겨요.

Google에는 필요한 연결만 요청해요

연결한 계정이 사용자가 지정한 계정인지 확인하기 위해 이메일과 계정 식별자를 사용해요. Drive 권한은 이 앱에서 사용하는 특정 파일을 다루는 범위인 drive.file을 사용해요.

장기 연결이 가능한 프로덕션 설정만 허용해요. 정기적으로 다시 로그인하도록 만드는 만료 주기를 추가하지 않아요. Google의 연결 해제나 보안 조치가 발생하면 직접 다시 연결해야 할 수 있어요.

운영과 문의

개인이 자신의 도서 목록을 관리하기 위한 보조 프로그램이에요. Google 연결 화면에 표시되는 사용자 지원 이메일로 문의할 수 있어요. 이 안내 사이트에는 프로그램의 로그인 기능이나 개인 도서 목록이 들어 있지 않아요.

Windows 10·11 64비트를 대상으로 해요. 실제 환경별 검증 범위와 배포 상태는 프로그램 폴더의 검증 기록에서 확인해요.
